# What to say when recording your own wake-word data. Used by record_session.py.
#
# Each [section] has its labels in the header: kind (pos/neg), similarity tier for negatives,
# pace, and which model it's for (mode = wake: stage 1 "jarvie, wake up"; sleep: "jarvie, go to
# sleep"; name: stage 2, "jarvie" alone while the bot runs). Each line below is one take; text in
# (parentheses) is HOW to say it, not something to say. "..." means a short natural pause.
#
# The full session plan is in RECORDING_GUIDE.md (next to this file). Record most for training,
# and a smaller set on a DIFFERENT DAY with --split test, so the test set never overlaps training.
# Use --repeats 2 on a section to say each line twice (it's fine if takes differ a little).
# Keep "slow" takes under ~2 seconds: the model only sees the last ~2 s of a phrase.
# Set macOS Mic Mode to Standard (Voice Isolation strips background noise).
